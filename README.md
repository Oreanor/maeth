# Maeth — Битва за Средиземье 4×4

React-игра, работающая одновременно в браузере и как Telegram Mini App.
Тактическая игра на доске 4×4 в духе шахмат: регистрация/вход, список друзей
(Telegram / Google), приглашение друга или игра против бота.

## Правила

16 уникальных фигур, у каждой — паттерн движения и дальность:

- `+` (ortho) — 4 прямых направления, `x` (diag) — 4 диагональных, `*` (all) — все 8.
- Дальность 1–3 клетки. Движение **скользящее**: путь должен быть свободен,
  фигура бьёт врага, останавливаясь на нём.

**Фаза 1 — драфт.** Игроки по очереди вслепую тянут фигуру из общей колоды (16,
без возврата) и ставят на любую свободную клетку. По 4 фигуры на сторону.

**Фаза 2 — ходы.** Каждая фигура ходит максимум один раз. Ходят по очереди
любой не ходившей фигурой; если ходить нечем — пропуск. Игра заканчивается,
когда ни у кого нет доступных ходов. **Побил больше фигур — победил**, поровну —
ничья.

**Дуэли.** Если ты бьёшь фигуру, которая нацелена и на твою атакующую (взаимная
угроза), бой контестится: оба кидают d6, атакующий побеждает при броске не
меньше (ничья кубика — в пользу нападающего, ≈58%). Исход показывается модалкой
с кнопкой «Закрыть» — игра ждёт. Неудачный удар всё равно тратит ход.
Бой по фигуре, которая не может ответить, проходит автоматически. Правило режет
ничьи (рандом ломает симметрию счёта) и чуть удлиняет партию.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (host: true — доступно с телефона по LAN)
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр прод-сборки
npm run typecheck
```

## Текущий статус (этап 1)

- **Без бэкенда.** Авторизация и список друзей — заглушки (`src/auth/`).
- **Игра против бота** работает полностью (драфт + ходы). «Игра с другом» пока
  запускает локальную партию с ботом под именем друга.
- В Telegram вход происходит автоматически из `initData`; в браузере — кнопки
  Google / Telegram / Гость (все ведут к синтетическому пользователю).

## Архитектура

```
src/
  platform/telegram.ts   обёртка над Telegram Mini App SDK (грейсфул в браузере)
  auth/                  AuthContext, типы, заглушки друзей
  game/
    pieces.ts            16 фигур: паттерн (+/x/*), дальность, эмодзи
    types.ts             модель доски, фигур, состояния (фазы draft/play/over)
    engine.ts            драфт, генерация ходов, применение, конец игры
    search.ts            alpha-beta поиск для фазы ходов (минимакс до конца)
    bot.ts               бот: эвристическая расстановка + ход через поиск
    useGame.ts           хук игровой сессии (обе фазы + бот)
  components/Board.tsx   рендер доски 4×4
  screens/               Login, Lobby, Friends, Game
```

Логика чистая и детерминированно-тестируемая: вся в `engine.ts`/`pieces.ts`,
UI зависит только от неё. Балансные правки (дальность/паттерн фигуры) — в
`pieces.ts`.
